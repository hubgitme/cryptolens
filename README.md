# 📊 کریپتو لنز — تحلیل تکنیکال ارز دیجیتال

داشبورد تحلیل تکنیکال با داده‌ی زنده‌ی Binance، قابل نصب به‌صورت PWA.

## ویژگی‌ها
- چارت کندل (Lightweight Charts) با تایم‌فریم 1H / 4H / 1D / 1W؛ بارگذاری خودکار هنگام باز شدن و تغییر ارز/تایم‌فریم
- اندیکاتورهای روی قیمت: EMA، SMA، Bollinger، VWAP، Volume
- پنل‌های جدا (ارتفاع ثابت، قابل تغییر اندازه، محور زمان فقط پایین‌ترین): RSI، RSI+SMA، MACD، Stochastic، ATR، OBV+SMA (با همترازی با TradingView)، ROC، ADX/+DI/−DI
- ابزارهای رسم: خط روند، افقی، فیبوناچی، الیوت 1-5 و ABC؛ جابجایی، Magnet و قفل (تکی/همه)
- اسکریپت‌های کاربر با کد (اندیکاتور و استراتژی شبیه Pine) + بک‌تست (بازده، درصد برد، Profit Factor، افت سرمایه)
- ذخیره‌ی خودکار همه‌چیز در مرورگر و پشتیبان‌گیری/بازیابی (فایل یا متن)

## ساختار پروژه
```
/
├── index.html          # ظاهر صفحه (HTML) و لینک فایل‌ها
├── style.css           # همه‌ی استایل‌ها
├── js/                 # به همین ترتیب در index.html بارگذاری می‌شوند
│   ├── core.js         # تنظیمات، localStorage، ارزها، تایم‌فریم، پشتیبان‌گیری
│   ├── indicators.js   # محاسبات خالص اندیکاتورها (بدون DOM)
│   ├── chart.js        # چارت، پنل‌ها، چیدمان، دریافت داده، رندر
│   ├── drawings.js     # ابزارهای رسم
│   ├── scripts.js      # اسکریپت کاربر، بک‌تست، ویرایشگر
│   ├── panel.js        # پنل «اندیکاتورها»
│   └── main.js         # راه‌اندازی + ثبت service worker
├── api/
│   ├── klines.js       # Serverless: دریافت کندل از Binance
│   └── proxy/[...path].js
├── sw.js               # service worker (Network-First)
├── manifest.json       # PWA
├── tests/              # تست‌های Node (بدون وابستگی)
├── tools/bundle.js     # ساخت نسخه‌ی تک‌فایلی
├── vercel.json
└── package.json
```

> فایل‌های `js/` اسکریپت‌های کلاسیک‌اند و در یک scope مشترک اجرا می‌شوند؛ **ترتیب** تگ‌های `<script>` در `index.html` مهم است.

## توسعه
```bash
npm test          # تست‌های اندیکاتورها، بک‌تست و اعتبارسنجی تنظیمات (Node 20+)
npm run bundle    # → dist/index.single.html  (کل پروژه در یک فایل HTML)
```

## استقرار (Vercel)
```bash
npm i -g vercel
vercel
```
پس از هر انتشار، مقدار `CACHE_NAME` در `sw.js` را یک واحد افزایش دهید.

## ذخیره‌سازی (localStorage)
`ta_settings_v1` تنظیمات و اسکریپت‌ها، `ta_drawings_v1` رسم‌ها، و لیست ارزهای ذخیره‌شده. همه در فایل پشتیبان هم هست.

## نکته‌ی امنیتی
اسکریپت‌های کاربر در مرورگر خود شما اجرا می‌شوند (sandbox کامل نیست)؛ فقط کد مورد اعتماد اجرا کنید. اسکریپت‌های واردشده از فایل پشتیبان غیرفعال وارد می‌شوند.
